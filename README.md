# 🃏 Super Trunfo - Comparações Avançadas (Nível Mestre)

Projeto final do desafio de lógica em C por **Willian Del Freu**.  
Neste programa, o jogador escolhe **dois atributos diferentes** para comparar entre duas cartas de países. O jogo calcula os valores, soma os dois atributos e determina a carta vencedora.

## ⚙️ Como compilar

```bash
gcc logicaSuperTrunfo.c -o supertrunfo

▶️ Como executar

./supertrunfo

🎮 Atributos disponíveis

1 - População
2 - Área
3 - PIB
4 - Pontos Turísticos
5 - Densidade Demográfica

Regra: maior valor vence, exceto na Densidade Demográfica, onde o menor vence.

🧾 Exemplo de execução

Escolha um atributo:
1 - População
2 - Área
3 - PIB
4 - Pontos Turísticos
5 - Densidade Demográfica
Escolha: 1

Escolha um atributo:
2 - Área
3 - PIB
4 - Pontos Turísticos
5 - Densidade Demográfica
Escolha: 5
